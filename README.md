# Refinery Unit III Plaju — Video Motion Canvas (30 detik)

Video penjelasan singkat tentang Refinery Unit III Plaju (Palembang, Sumatera Selatan), dibuat dengan [Motion Canvas](https://motioncanvas.io).

Hasil render: [`video/refinery-unit-iii-plaju.mp4`](video/refinery-unit-iii-plaju.mp4) — 1920×1080, 30 fps, 30 detik.

## Alur video
| Waktu | Isi |
|---|---|
| 0–5 s | Judul + siluet kilang dengan api flare |
| 5–11 s | Lokasi: Kilang Plaju & Sungai Gerong di tepi Sungai Musi / Komering |
| 11–17 s | Sejarah: 1904 (Shell/BPM), 1926 (Stanvac), 1965 & 1970 (Pertamina) |
| 17–22 s | Kapasitas ± 118 ribu barel/hari + alur proses |
| 22–27 s | Produk: Gasoline, Avtur, Solar, LPG, Polypropylene (Polytam), Musicool |
| 27–30 s | Penutup |

## Menjalankan
```bash
npm install
npm start          # buka http://localhost:9000, lalu klik RENDER
```
Hasil render tersimpan di `output/project.mp4`. Scene ada di `src/scenes/refinery.tsx`.
